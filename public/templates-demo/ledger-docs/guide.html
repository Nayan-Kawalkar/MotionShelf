Authentication

Every request is signed with a key scoped to one project.

Create a key in the dashboard, then send it in the Authorization header. Keys are shown once — store them in your secret manager, not in source.

Rotate a key by issuing a new one before revoking the old, so no request is ever unauthenticated.
